# Awesome Minishop 预览资源

目录数据：`docs-site/src/data/awesomeMinishop.ts`；页面：`/awesome-minishop/`。图片存于本地，避免依赖外部图片托管。

中文目录使用本地原创 SVG 主题简介封面，封面不是界面截图；实际外观请查看作者仓库。每张卡片显示作者及项目链接。

以下 WebP 是于 2026 年 10 月 2 日取自作者公开仓库的原始预览归档，未修改内容；中文目录不再直接展示其中的俄文界面。

`kiro-wheel.svg` 和 `ai-support.svg` 是本目录原创示意封面，不是项目截图，图片替代文本也注明了这一点。

新增项目时，在对应类别增加记录、本地预览（建议 8:5）、清晰 `previewAlt`，并在表中记录来源。点击预览可打开完整图片。

类别图标来自 Google Noto Emoji，缩小到 112×112 时保留动画；`category-*-static.webp` 是首帧，供减少动态效果偏好使用。
