# 从其他机器人迁移

本节提供已支持来源迁移到 Remnawave Minishop 的操作指南。每种迁移使用独立 Markdown，说明具体步骤、限制、命令和核查方式。

| 来源 | 支持范围 | 文档 |
| --- | --- | --- |
| [remnawave-tg-shop](https://github.com/kavore/remnawave-tg-shop/) | 完整迁移全部数据 | [操作指南](remnawave-tg-shop.md) |
| [Remnashop](https://github.com/snoups/remnashop/) | 自动导入用户、订阅、付款、邀请、激活码和支持的支付设置 | [操作指南](remnashop.md) |
| [Bedolaga](https://docs.bedolagam.ru/) | 数据清点及账号、订阅、财务、礼品、运营数据的幂等导入 | [操作指南](bedolaga.md) |

这些是上游迁移能力参考，不代表本项目已经批准或执行生产数据迁移。操作前应使用隔离环境及备份验证。
