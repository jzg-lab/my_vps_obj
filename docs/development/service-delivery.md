# 独立服务交付与专用出口

B 包开发检查点，2026-10-23。基点 `ace47463`，迁移 `0114_service_delivery`。
本文记录本包实现与验证边界，需求/产品和月度计量规则由主窗口维护。

## 接口与流程

- `GET /api/services/{service_id}/subscription`：仅允许当前所属账号，其他账号返回 404；
  封禁、暂停、耗尽、到期、待交付和未确认变更均不返回凭据。不读取账号旧身份，
  旧订阅路径继续 410。每次重新读取该服务的面板身份、归属标记、节点组、额度和到期。
  仅接受 HTTPS 链接，响应 `private, no-store`，服务列表不包含链接。
  必须是 `ready` 身份；激活前的 pending 准备检查不能代替此条件。新读取的累计用量
  使用 A 的观测函数保存；即使因耗尽或计数异常拒绝返回链接，也不丢弃该观测。
- 用户详情使用现有 `CopyLinkField`，按需加载本服务链接；关闭详情即销毁，不写浏览器
  存储，不记录返回的 URL。手动导入/更新说明只指向该份订阅，不自动选择其他服务。
- `POST /api/admin/services/{service_id}/deliver`：管理员提交账号、服务版本和幂等键。
  已准备身份、可用累计观测和专用资源核验齐备后，保存 `deliver` 操作记录及同步意图。
  worker 在所属账号锁内调用 A 的共用同步，确认禁用准备状态、条款和计量；只有
  共用同步成功、无待确认项且可交付时，才将 ready 与下一次同步标记一起提交。
  随后仍由 A 的共用入口决定是否启用。崩溃后可以重试，期间的暂停、封禁、到期与
  耗尽仍优先生效。重复请求不会更换身份、重置计数或新增额度。
- `POST /api/admin/services/{service_id}/revoke`：管理员提交账号、版本、幂等键和原因。
  保存取消决定及永久撤销意图后由现有身份 worker 重试；不修改额度或补发身份。
  查明归属、确认禁用后保存最后可读累计观测，再删除远端身份并重新查询不存在。
  异常计数保留待核对，不通过删除掩盖问题。最后观测先提交，避免 DELETE 后崩溃丢失。
  创建曾超时且尚未绑定 ID 时，空查询不能证明迟到创建已结束，撤销继续等待核对。
  月度切点仍待确认时，保存最后累计观测与时间，保留旧周期和切点，保持停用但不删除
  身份；正在接入 A 的终止结算，不能把冻结的上一周期页面用量称为最终用量。
  面板确认不等于实际 Node 长连接已停止。历史保留取消原因与原条款，不能恢复该服务。
- `POST /api/admin/dedicated-exits/{exit_id}/verify`：提交资源版本、当前服务 ID（未分配为 null）、
  实际观察时间、出口 IP、固定/独享确认及证据。地址必须与库存一致。该操作是管理员
  记录实测证据，不是系统自动执行网络核验。
- `POST /api/admin/dedicated-exits/{exit_id}/reclaim`：同样携带版本和所属服务，要求身份已撤销，
  且实际停用与旧配置拒绝证据发生在撤销确认之后。仅此操作解除 IP 绑定；到期、暂停或
  面板返回成功均不会自动释放。释放后清除旧核验标记，新分配需要重新核验。
- `GET /api/admin/dedicated-exits/{exit_id}/audit`：分页管理员审计，保留原服务、操作人和证据。
  原账号删除不级联删除这些记录。证据中不得填写订阅 URL 或凭据。

分配、核验、回收使用资源行锁和版本；终止服务与账号操作使用所属账号行锁。
相同请求键返回原记录；不相同的请求内容拒绝。已回收请求的重放不会释放后续分配。
固定出口故障不自动改 IP、切共享线路或重新分配。资源故障替换规则仍由用户决定。

## A 的依赖

B 消费 `panel_traffic_limit`、带 `connection` 的 `matches_service_terms`、
`service_ready_for_delivery` 和 `synchronize_service_entitlement_locked`。
已接入 A 的实现 `1476ddb1`（本分支对应 `ef639b3b`）；pending 到 ready 的交付调用
共用同步，并额外检查 `sync_pending == False` 与可交付条件，不能仅依赖同步返回值。
月度累计限额和固定检查点由 A 唯一计算，B 不清零计数、不换身份补额度。
