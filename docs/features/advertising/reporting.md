# 广告报表

本页是[广告兼容参考](./index.md)。报表中的产品购买、外部入账和退款使用上游付款口径，不从本项目人工开通数量或套餐模板价格推算；没有付款证据时不能声称已获得销售转化。

在“概览”选择模式和时间段。边界使用 UTC，包含开始、不包含结束。“期间事件”显示期间发生事件；“首次接触群组”按账号首次来源选出群组，跟踪后续购买。

外部入账、产品交易额和退款分开统计。余额充值计入入账，余额购买计入产品购买，同一笔钱不会重复计入产品交易额。部分余额付款计入订单两部分。已知首购后，续费和加购属于复购；退款不会将下次购买重新变成首购。

RUB、Stars／XTR 和其他币种分别显示，不按当前汇率自动换算。金额以最小货币单位保存，配置变化不改历史快照。旧活动成本代表不带时间段的 RUB 总费用。设置中必须选择唯一费用来源：旧成本、人工记录或导入。

ROAS 使用产品净交易额。获客成本（CAC）以已知首购用户计算。缺少成功顺序的旧历史不虚构新买家。分母缺失显示 `—`，不显示零转化。

D7、D30、D90 表示首次接触后的交易额，已完成窗口单独显示；比较时应选择成熟度相同的群组。平台汇总展示／点击不会转换为 Minishop 用户。

“接触与购买”提供分页历史。CSV 导出会转义可能被表格软件当成公式的值。

指标定义见[术语](./glossary.md)。

链接、渠道和依据筛选只缩小本地接触及订单来源范围。广告平台费用与聚合属于整个活动，使用这些筛选时显示“无数据”，不计算 CAC、ROAS。群组归属及成熟度由用户首次来源决定，订单筛选不会改写它们。
