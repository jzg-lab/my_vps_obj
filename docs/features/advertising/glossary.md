# 广告统计术语

本页定义[广告兼容报表](./index.md)的口径。购买与收入来自上游付款记录；本项目 `ServicePlan` 的标价、`UserService` 的权益及人工开通记录都不能单独证明实际收款。

| 指标 | 统计内容 |
| --- | --- |
| 接触 | 保存的链接访问、UTM 参数组或机器人事件 |
| 匿名访客 | 安全 cookie 中不直接暴露身份的标识，尚未关联账号 |
| 新用户 | 已验证的新账号，且与接触记录关联 |
| 回访用户 | 接触前已存在的账号 |
| 首次来源 | 账号最早已知来源，与购买来源分开保存 |
| 购买来源 | 下单时归因窗口内最近一次符合条件的接触 |
| 产品购买 | 成功的订阅、试用、礼品或加购订单；余额充值单独统计 |
| 外部入账 | 通过外部支付方式收到的资金 |
| 净交易额 | 产品交易额减退款 |
| 广告支出回报率（ROAS） | 同币种产品净交易额／广告费用 |

ROAS 不包含成本、手续费、税费和服务成本，不等于利润或投资回报率（ROI）。分母缺失时比率未知，界面显示 `—`，API 返回 `null`。

旧 `first_start_at` 只代表最早已知机器人来源，不证明注册。没有成功日志的旧付款，其精确成功时间和首购顺序未知。广告平台数据与 Minishop 已验证事件分开显示。
