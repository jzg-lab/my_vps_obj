# 广告链接优惠

在“优惠”中，将已有激活码绑定到活动或单条链接。广告模块复用常规代码机制，应用时仍校验有效期、范围、次数与用户限制。单用户专属代码不能公开为活动优惠。

结账效果自动填入下单表单，用户可手动替换。独立奖励则填入激活字段，必须由用户操作才发放。单纯访问不发放订阅、余额或推荐奖励。

如果无链接时也需由代码决定订单来源，选择“手动输入来源”。只有代码与一个活动存在唯一有效绑定时才生效；多个活动共用代码不能单独确定来源。符合条件的链接接触优先于手动代码。

绑定保留版本，同一范围的新绑定会结束前一个版本。修改代码条件会保留旧版本，订单保存当时生效条件快照。绑定历史和独立的激活、购买、待付款、退款计数，可区分优惠效果和广告来源注册。

代码规则见[激活码](../promocodes.md)，金额指标见[报表](./reporting.md)。
