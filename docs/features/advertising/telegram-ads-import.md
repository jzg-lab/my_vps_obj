# 导入广告平台指标

打开“导入 CSV”，选文件或粘贴正文，设置广告账号、时区、分隔符和粒度，再明确映射各列。必须包含区间开始或事件时间，以及广告 ID。展示、点击、启动、费用可选；填写费用时必须有币种。

以下为虚构日粒度示例：

```csv
date,ad,impressions,clicks,starts,cost,currency
2026-09-01T00:00:00Z,example-1,1000,50,12,500,RUB
```

最大 1 MiB、5000 行，支持 BOM、逗号、分号和制表符。日期须为 ISO 8601。本地时间按所选时区解释；夏令时切换中的歧义时间必须明确偏移。任何错误行都会拒绝整个文件，不部分应用。

“预览”不计入统计；“确认整个导入”应用全部已验证行。重复确认同一导入不会重复计数。修正文件必须明确允许替换相同区间。不同粒度的重叠区间不能相加或静默替换。“撤销导入”移除本批指标并恢复先前已确认版本。

人员匹配只支持具有时间的独立事件。指定机器人 ID 和秒数窗口；候选包含自然启动和其他活动。时间接近不能证明身份，即使运营者确认也只是推测，不触发权益或奖励发放。

需要明确列映射的适配器不代表支持所有 Telegram Ads 导出格式。核查具体广告账号需要该账号的脱敏文件。见[报表](./reporting.md)、[排障](./troubleshooting-limitations.md)。

API `/api/admin/ads/{campaign_id}/imports/preview` 也接受 `text/csv`：元数据和 JSON `mapping` 放查询参数，CSV 放请求体。浏览器表单将 CSV 与元数据一起提交为结构化 JSON。

展示、点击、启动列缺失或单元格为空表示无数据，区别于明确 `0`。不完整聚合显示“无数据”；缺少点击或展示任一值时不计算点击率。
