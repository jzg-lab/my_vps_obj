# 广告与客户来源

在后台打开“广告”，创建活动，再选择“打开活动”。活动详情整合链接、优惠、接触记录、费用、导入和修改历史。关闭 Telegram 后，网页链接仍可使用。

先为每条广告创建独立链接，再用测试账号检查访问、登录与购买。费用可手动录入或导入；每个活动只能选择一个费用来源。

| 章节 | 用途 |

| [术语](./glossary.md) | 理解接触、注册和购买指标 |
| [活动与链接](./campaigns-links.md) | 公开地址、UTM、暂停和归档 |
| [登录与来源](./attribution-auth.md) | 将访问关联至已验证账号 |
| [优惠](./promocodes.md) | 绑定已有激活码 |

| [核查与限制](./troubleshooting-limitations.md) | 排障及测试场景 |
