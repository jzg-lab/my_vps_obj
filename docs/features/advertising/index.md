# 广告与客户来源

本节属于[上游兼容与可选扩展](../../upstream/index.md#广告与来源统计)，保留活动链接、访问归因、报表及历史维护能力。本项目一期由管理员人工开通独立服务，不开放营销购买流程；广告入口、采集开关或模拟数据均不代表在线支付已接入。

广告访问与登录记录应按其自身开关和权限判断，不能因商业流程退役就宣称所有广告功能关闭。下文“购买”指上游订单，不能把 `ServiceOrder` 人工开通记录直接当作现金收入、已付款转化或伙伴佣金。项目实现及环境验收范围只查[本轮本地最终验收](../../implementation-plan.md#本轮本地最终验收)。

维护已采用该能力的部署时，在后台打开“广告”并进入活动详情，查看链接、优惠、接触记录、费用、导入和修改历史。关闭 Telegram 后，网页链接仍可使用。每条广告使用独立链接；访问与登录、购买与退款应分别按实际开放能力验证。费用可手动录入或导入，每个活动只能选择一个费用来源。
